# Repwise 4.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Visible magic-link sign-in, a built-in supplement library with a seeded stack, a shorter Profile built from sheets, and loud water nudges backed by server push.

**Architecture:** Pure domain helpers come first, test-first: auth URL parsing, supplement catalogue and seeding, water pace, supplement overdue checks, profile summaries and the push decision. Thin React UI sits on top. Push is a Supabase table, plus an hourly edge function whose decision logic is a pure module that Vitest can import.

**Tech Stack:** React 18, Zustand, TanStack Query, motion, dayjs, Tailwind 4, Vitest, puppeteer e2e, Supabase (auth, Postgres, Edge Functions on Deno, pg_cron + pg_net), `npm:web-push`.

**Spec:** `docs/superpowers/specs/2026-10-18-repwise-v4-2-design.md`

## Global Constraints

- Sign-in stays magic link only. No OTP code entry and no passwords.
- New `AppData`/`Profile` fields are optional or defaulted in `normalize`, so documents saved before 4.2 load.
- Seeding supplements never changes `meta.updatedAt`.
- Pre-filled stack: creatine "5 g" (`any`), whey protein "1 scoop" (`post`), multivitamin "1 tablet" (`meal`). Use the catalogue ids `creatine`, `whey-protein` and `multivitamin`.
- `waterReminders` default: `{ on: false, from: 9, to: 21, everyHours: 2 }`. Hours are local.
- Supplement overdue cutoffs: morning 11:00, meal 14:00, night 22:00. `pre`, `post` and `any` are due by 18:00.
- Push copy: title "Time for water", body "{glasses} of {goal} glasses. You're {behind} behind, have one now.", url `/#/today`.
- In-app water copy: "{glasses} of {goal}. You're {behind} behind. Have one now."
- Catalogue notes give a typical dose and timing only. No health claims.
- Keep the current iOS look and existing UI kit (`Card`, `List`, `Row`, `FieldRow`, `Sheet`, `Switch`, `Select`). Motion respects reduced motion.
- Supplement timings: `SuppTiming = 'morning' | 'pre' | 'post' | 'meal' | 'night' | 'any'`. Day order is `morning, pre, post, meal, night, any`.
- Version becomes `4.2.0`. The Profile footer reads `__APP_VERSION__`.

## Review Focus

1. **A normal relaunch with a stored session shows no "You're signed in" banner.** Only a sign-in that arrived by link, or one found by a foreground re-check, shows it. The test lives in Task 2 (`signInNotice`).
2. **A document that already has supplements, including only archived ones, is never re-seeded, and an imported or cloud document with `suppSeeded` absent but a non-empty stack keeps that stack unchanged.** Test in Task 3.
3. **A zero water goal, or a reminder window where `to <= from`, never produces a nudge or a divide-by-zero.** Test in Task 5 (`waterPace`) and Task 7 (`decideNudge`).
4. **A bad or unknown `tz` string on a subscription row skips that row and never crashes the whole cron run.** Test in Task 7.
5. **Turning water reminders on while signed out, or with permission denied, leaves `waterReminders.on` false.** Test in Task 8 (`enableReminders` result handling).
