# Groups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Members of a group (family, gym gang) see each other's training read-only, compete on a fair weekly scoreboard, and send rate-limited nudges that buzz Android phones.

**Architecture:** Supabase tables `groups`, `group_members` and `nudges` hold the social layer. A `security definer` function `member_doc` hands out another member's `AppData` with body fields stripped per group. Two JWT-verified edge functions handle the server work: `group-nudge` (decide, insert, push) and `member-photos` (5-minute signed URLs). The client adds a Groups tab and fetches members with TanStack Query. It reuses the History and Progress components through a `DocContext` that carries `{ data, readOnly }`.

**Tech Stack:** React 18, TypeScript strict, Tailwind v4 with shadcn-style components, TanStack Query, Zustand, motion, dayjs, Supabase (Postgres RLS, Deno edge functions, `npm:web-push@3.6.7`), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-13-groups-design.md`

## Global Constraints

- Groups require sign-in. Signed out, the Groups tab shows an explanation and `SignInCard`.
- A group has at most 12 members. Group names are 1–40 characters, display names 1–24, nudge notes up to 80.
- Invite codes are 6 characters from the alphabet in `src/domain/training/splits/custom.ts`.
- Nudge rate limit: one sender to one receiver at most once per receiver-local day. Each receiver gets at most 2 nudge pushes per local day.
- Awake window: the water-reminder `from`–`to` when water reminders are on, otherwise 08:00–21:00.
- Member photo URLs are valid for 300 s, and the client caches them for at most 240 s.
- Member docs are never persisted (no IndexedDB, no Zustand) and are never passed to `act`, `useApp.replace` or sync.
- `schemaVersion` stays 4. The only new document field is optional `profile.displayName`.
- Copy is in plain words, and every async surface has loading, empty, error and success states.
- Motion honours `prefers-reduced-motion`.
- The scoreboard never ranks by raw kilos or volume, and nothing gets negative styling.

## Review Focus

1. **A member with no `daysPerWeek` or an empty document.** The board must show "0 / 3" and a dash rather than NaN or a crash. Test in Task 1.
2. **A nudge to someone with no push device, or only an iPhone.** The row is still inserted and the sender sees "Sent" (not an error). Test in Task 3.
3. **Turning water reminders off on a phone that also takes nudges.** The device keeps nudges, and the row survives with `kinds = {nudges}`. Test in Task 5.
4. **A signed-out user opening an invite link.** After the magic link, they land on the join sheet with the code filled in. Test in Task 6 (`pendingJoin` round trip).
5. **The viewer and the member in different time zones.** The board uses the viewer's week, and the nudge uses the receiver's local day. Tests in Task 1 and Task 3.
